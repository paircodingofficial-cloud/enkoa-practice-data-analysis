# 토픽 모델링 심화 가이드 — 진행 체크리스트

지난 단원에서 배운 **임베딩·코사인 유사도**를 발판으로, 문서를 **자동으로 군집 짓고(군집화)** 군집마다 **주제를 뽑아내는(BERTopic)** 하루입니다.
새 통계는 배우지 않습니다 — 임베딩 → 차원 축소(UMAP) → 군집화(HDBSCAN) → 토픽 추출(BERTopic)로 이어지는 **한국어 텍스트 파이프라인**을 손에 익힙니다.
완료 기준은 자가채점 `✅ 통과!`(서술·그래프 문제는 서술 셀 작성·완성 그래프처럼 그리기).

> 교안은 **뉴스 헤드라인(스포츠·경제·IT과학·세계)** 으로 "군집이 실제 분야를 복원"하는 과정을 시연하고, 과제는 **실제 상품 리뷰(선크림·자세밴드)** 로 라벨 없이 관심 주제를 발견합니다. 강사용 완성본은 `정답/` 폴더.
>
> **함께 따라하기는 시연과 다른 대상을 맡습니다.** 시연이 토픽 0의 키워드를 보면 따라하기는 토픽 1을, 시연이 `min_topic_size` 10·30·50을 비교하면 따라하기는 40으로, 시연이 HDBSCAN 노이즈(-1) 개수를 세면 따라하기는 가장 큰 토픽의 크기를 세는 식으로 — 코퍼스는 하나로 두되 **묻는 것을 바꿉니다**. 토픽 모델링은 하나의 코퍼스를 임베딩 → 축소 → 군집 → 키워드로 끝까지 관통하는 것이 핵심이라, 중간에 데이터를 바꾸면 흐름이 끊깁니다.

## 2. 교안_02 BERTopic 토픽 모델링 (강사와 함께)

- [ ] 서두: 목표 + `⏪ 복습`(임베딩·UMAP·군집) + `데이터 살펴보기`
- [ ] 1 BERTopic 이란 — **4단계 파이프라인 흐름도**(1800건 → 768차원 → 5차원 → 토픽 14개+노이즈 406건), baseline + `get_topic_info` + 🖐️ + ✅
- [ ] 2 토픽 해석 — `get_topic`(키워드)·`get_representative_docs`(대표 문서) + **c-TF-IDF 원리 그림**(토픽 하나 = 한 편의 큰 문서) + 🖐️ + ✅
- [ ] 3 한국어 키워드 — `korean_tokenizer` 로 c-TF-IDF 깔끔하게 + 🖐️ + ✅
- [ ] 4 `min_topic_size` — 토픽 수·노이즈 조절(10/30/50 비교) + 🖐️ + ✅
- [ ] 5 토픽 수 조절 — `nr_topics`·`reduce_topics`·`merge_topics` + 🖐️ + ✅
- [ ] 6 시각화 — `visualize_barchart`·`visualize_heatmap`·`visualize_hierarchy`·`visualize_documents` + 🖐️ + ✅
      · 히트맵의 진한 칸·계층도의 먼저 붙는 가지 = 5절 `merge_topics` 의 **합칠 후보** (5절이 '어떻게', 6절이 '무엇을')
- [ ] 7 새 문서에 토픽 붙이기 — **`fit_transform`(학습) vs `transform`(추론)** 차이, 새 헤드라인 3건 배정, `prediction_data=True` 가 왜 필요했는지 + 🖐️(코퍼스에 없는 주제 → 노이즈 −1 확인) + ✅
      · 과제 LV2 문제5 가 이 `transform` 을 그대로 씁니다 — 여기서 반드시 짚고 넘어갈 것
- [ ] `🚀 응용 클론코딩` — 뉴스 토픽 리포트(토픽별 키워드+대표문서+크기)
- [ ] 8 **키워드 뽑는 방식 바꾸기** — `representation_model=KeyBERTInspired()`, c-TF-IDF 와 나란히 비교
      · **이 데이터에선 기본(c-TF-IDF)이 더 읽힌다** — "새 도구가 늘 낫지 않다, 비교해서 고른다"가 이 절의 핵심
- [ ] `🔮 맛보기` — 토픽 키워드+대표문서를 LLM 에 주고 **토픽 이름 자동 생성**(다음 단원 예고) + ✅
      · `.env` 에 `OPENAI_API_KEY` 가 있으면 실호출, 없으면 건너뜀(과금 없음). `.env.example` 복사해 채우면 됨
      · 여기서 가르치는 건 API 사용법이 아니라 **"토픽 모델링의 마지막 칸(이름 붙이기)을 LLM 이 채운다"** 는 그림
- [ ] `이번 강의 정리` + `⏭️ 예고`(OpenAI API 활용)

## 3. 과제 — 상품 리뷰 토픽 분석 (자기 주도)

> 라벨이 없는 실제 리뷰에서 **관심 주제를 스스로 발견**합니다. 각 문제의 답안 셀(`# 여기에 코드를 작성하세요`)을 채우고, 바로 아래 자가채점(`# [자가채점]`)에서 `✅ 통과!` 를 확인하세요. 막히면 `힌트` 를 펼칩니다.

### 과제_LV1_기초 — 선크림 리뷰 (단일 개념, 11문)

- [ ] `데이터 살펴보기`(제공 코드 실행) → 1 데이터 살펴보기(서술)
- [ ] 2 임베딩 불러오기·모양 확인 / 3 리뷰 한 개의 벡터 살펴보기
- [ ] 4 코사인 유사도 top3 / 5 **HDBSCAN 직접 군집**(`fit_predict` — 교안_01 §3 을 과제에서 이행)
- [ ] 6 UMAP 산점도(완성 그래프처럼 그리기)
- [ ] 7 BERTopic 주제 추출 / 8 대표 키워드 / 9 대표 문서
- [ ] 10 어디에도 안 묶인 문서 세기 — 노이즈(−1) 토픽
- [ ] 11 토픽별 문서 수 막대그래프(완성 그래프처럼 그리기)

### 과제_LV2_응용 — 자세밴드+선크림 (개념 조합, 9문)

- [ ] `데이터 살펴보기` → 1 데이터 살펴보기(서술)
- [ ] 2 제품 종류별 색 임베딩 지도(완성 그래프처럼 그리기)
- [ ] 3 BERTopic 으로 두 제품군의 주제 뽑기
- [ ] 4 대표 문서를 제품 종류와 대조
- [ ] 5 새 리뷰를 토픽에 배정
- [ ] 6 토픽 × 제품 종류 교차표
- [ ] 7 굵게 vs 잘게 — 내장 시각화 3종(막대·히트맵·계층도)을 `min_cluster_size` 25(토픽 2개)와 10(토픽 6개) 두 모델로 그려 비교
      · 토픽이 2개뿐이면 히트맵·계층도는 볼 것이 거의 없다 → **토픽 수가 그림의 쓸모를 바꾼다**를 몸으로 확인
      · plotly Figure 라 `plt.show()` 가 아니다. 한 셀에 그림이 여럿이면 마지막 하나만 렌더되므로 그림마다 `fig.show()`
- [ ] 8 **키워드 뽑는 방식 바꿔 비교**(`KeyBERTInspired`) — 군집은 그대로, 붙는 단어만 달라짐 · 어느 쪽이 나은지 직접 판단
- [ ] 9 **LLM 에게 토픽 이름 맡기기** — `representation_model` 에 OpenAI 를 끼워 `Name` 컬럼을 사람 말로 (키 없으면 채점 제외)

### 과제_LV3_통합 — 미니 프로그램 2개

- [ ] **1 리뷰 토픽 리포트 생성기**(선크림): 1단계 로드·살펴보기 → 2단계 BERTopic 학습(`min_cluster_size=20` — LV1 의 15 와 다르게) → 3단계 토픽 정리(`reduce_topics`) → 4단계 토픽별 리포트 표 → 5단계 정렬·CSV 저장(`output/topic_report.csv`) → **6단계 LLM 토픽 이름 붙이기**(`topic_report_named.csv`, 키 없으면 제외) → 인사이트(서술)
- [ ] **2 문서 주제 탐색기**(밴드+선크림): 1단계 로드 → 2단계 BERTopic 주제 탐색(`min_cluster_size=10`) → 3단계 토픽별 대표 키워드·대표 문서 → 4단계 토픽 프로파일 표(노이즈는 따로) → 5단계 토픽 산점도·토픽 × 상품군 교차표·**검증 컬럼을 붙인 `profile_check` 저장**(`output/topic_profile_check.csv`) → 인사이트(서술)
