## 1. 교안_01 가설검정 (강사와 함께)

- [ ] 1 가설검정 프레임 — H₀/H₁·유의수준 α·검정통계량·p-value(귀무분포 꼬리)·1종/2종 오류
- [ ] 🔧 주력 도구 **Pingouin**(`pg`) 소개 — 검정+효과크기+신뢰구간을 표 하나로 (대안: scipy/statsmodels)
- [ ] 2 가정 점검 — 정규성 `pg.normality`·`pg.qqplot`(Q-Q), 등분산 `pg.homoscedasticity`
- [ ] 3 t-검정 3종 — 1표본 `pg.ttest(x, 기준값)` / 대응 `pg.ttest(a, b, paired=True)` / 독립 `pg.ttest(a, b, correction=)`(Student vs Welch) + Cohen's d(자동)
- [ ] 4 모수 vs 비모수 — 선택 기준, `pg.mwu` + RBC·CLES, 그리고 나머지 두 짝 **`pg.wilcoxon`(대응)·`pg.kruskal`(3집단+)** 직접 실행
- [ ] 5 분산분석(ANOVA) — `pg.anova`(np2=η²) + 사후검정 `pg.pairwise_tukey`(다중검정 문제) / 이분산이면 `pg.welch_anova`+`pg.pairwise_gameshowell`
- [ ] 6 카이제곱 — 적합도 `scipy.stats.chisquare`(🔧 pg 미지원) / 독립성 `pg.chi2_independence`(Cramér's V 자동) + 조정된 잔차(statsmodels)
- [ ] 7 검정 선택 가이드 — 데이터 유형별 의사결정
- [ ] 🚀 응용 클론코딩 — 교육 전후 **대응표본 t** + 채널별 만족도·재문의율로 **개선안 검증 리포트**

## 2. 교안_02 회귀분석 (강사와 함께)

- [ ] 1 상관에서 회귀로 — r → r²(결정계수) → 예측, 상관 ≠ 인과
- [ ] 2 단순 선형회귀 — `smf.ols('y ~ x').fit()`·`.summary()` 읽기(coef·P>|t|·R²), 단순회귀 R² = 상관 r²
- [ ] 3 다중 선형회귀 — 여러 변수, Adj R²·계수 p-value·다중공선성(VIF 개념)
- [ ] 4 회귀 진단 — 잔차 vs 적합값·잔차 Q-Q·Durbin-Watson(독립성)
- [ ] 5 종합 워크플로와 한계 — 상관 ≠ 인과, 외삽 위험, 통계적 유의 ≠ 실질적 유의
- [ ] 🚀 응용 클론코딩 — 상관 → 다중회귀 → **표준화 계수로 영향력 비교** → 진단(VIF·DW)까지 **만족도 예측 리포트**

### 과제_LV3_통합 — 3문 18단계 (권장 150분+) · **뉴욕 택시 운행 기록(taxis)** 데이터

> 지금까지 과제는 이미 깨끗한 데이터로 시작했지만, 이 원본에는 **결측치·불가능한 값·문자로 저장된 날짜**가 섞여 있습니다. **전처리부터 직접** 해야 분석을 시작할 수 있습니다.

- [ ] 1 **원본 전처리** (구조 파악 → 날짜 파싱·`소요시간_분` 파생 → `팁비율` 파생 → 결측 행 제거 → 이상치 제거 → 정제본 저장)
- [ ] 2 **가정 점검과 비교 검정** (정제본 로드 → 정규성·등분산 → Mann-Whitney → **결과 뒤집어 보기** → Kruskal-Wallis + 상자그림 → 카이제곱 + Cramér's V → 해석 서술)
- [ ] 3 **회귀와 의사결정** (정제본 로드 → 단순회귀 → 다중회귀 → VIF → 잔차 진단 그래프·Durbin-Watson → 예측 + 의사결정 리포트)

> **문제 2 의 핵심 함정**: 현금 결제의 팁은 **미터기에 기록되지 않아 전부 0** 입니다. 그래서 '결제수단별 팁비율' 검정은 p ≈ 0 으로 압도적으로 유의하지만, 이는 **승객 행동이 아니라 기록 방식의 차이**입니다. 검정 결과를 해석하기 전에 **그 숫자가 어떻게 만들어졌는지** 확인해야 한다는 것을 직접 겪습니다.

### [참고] 참고_AB테스트 — 교안 3부 7절 + 실습 2문 (권장 120분+) · **웹 A/B 실험(ab_data)** 데이터

> **본 교안·과제와 별개인 참고 자료**입니다. A/B 테스트는 9일차 도구(비율 검정·효과크기·신뢰구간)를 **비즈니스 의사결정**에 쓰는 응용편이라 따로 묶었습니다. LV1·LV2 를 마친 뒤 이어서 보세요.

- [ ] **1부 실험 설계**(시작 전) — 1 무작위 배정과 인과 · 도구를 설계용/해석용으로 구분 / 2 설계 4요소(가설·지표·α와 검정력·MDE) / 3 표본크기·실험 기간 산정 + peeking 금지

- [ ] **3부 의사결정** — 7 유의성·크기·사업 판단을 엮은 결론 문장, 판단이 갈리는 세 경우
- [ ] ✅ 따라하기 3개(표본크기 계산 · 더 큰 표본 · 결론 한 줄) + 바로 확인 퀴즈 3개

**실습 문제 파트**
- [ ] 실습 1 A/B 전환율 분석 (로드·구조 → 정제(불일치·중복 제거) → 그룹별 전환율 → 막대그래프 → z-검정·Cohen's h → 95% 신뢰구간 → 의사결정 서술)
- [ ] 실습 2 대용량 표본과 실질적 유의성 (**원본 재로딩·재정제** → 전환율 차이·상대변화 → 검정·효과크기 → 비교 그래프 → 통계적 vs 실질적 유의성 서술 → 표본크기 산정)

## 막혔을 때

- [ ] 문제 맨 위 `pd.read_csv(...)` 셀부터 다시 실행. 각 문제는 원본 재로딩 또는 `.copy()` 로 시작.
- [ ] 결측치가 있는 열(titanic age·penguins 체중)은 검정 전에 `dropna()`
- [ ] `pg.ttest(a, b)` 의 기본은 Student(`correction=False`) — 등분산을 확신 못 하면 **Welch(`correction=True`)**. 대응표본은 `pg.ttest(a, b, paired=True)`(차이값 정규성만 확인). 결과 표의 `cohen_d`·`CI95`·`power` 를 함께 보기
- [ ] 회귀는 `smf.ols('y ~ x1 + x2', data=df).fit()` → `print(model.summary())` 로 계수·p-value·R² 확인
- [ ] 그래프 문제는 **자동 채점이 없습니다** — 완성 그래프 스크린샷과 같은 모양으로 그리세요
- [ ] p-value 만 보지 말고 **효과크기**(Cohen's d·η²·Cramér's V·Cohen's h)로 "얼마나 큰 차이인지"도 판단
