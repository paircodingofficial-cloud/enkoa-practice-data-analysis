# 가설검정·회귀분석 실습 가이드 — 진행 체크리스트

지난 시간에 **신뢰구간으로 주장을 판단**한 것을 이제 **귀무가설·p-value 를 갖춘 정식 가설검정**으로 공식화하고, **상관 → 회귀**로 나아가 데이터로 의사결정하는 하루입니다.
아래 체크박스를 순서대로 지워 나가세요. 완료 기준은 **자가채점 셀에서 `✅ 통과!`**(서술형은 서술 셀 작성, **그래프 문제는 "완성 그래프(정답)" 와 같은 모양으로 그리기**).

> 통계는 별도 이론 수업이 없으므로 교안에 이론을 충분히 담았습니다.
>
> 교안은 강사 **시연**을 **자동차 연비(mpg) + 훈련 기록**으로 보고, **함께 따라하기는 시연과 다른 데이터 — 고객센터 상담 기록**(`callcenter_calls.csv`·`callcenter_agents.csv`)으로 직접 연습합니다. 과제는 또 레벨마다 다른 데이터 — **LV1 타이타닉 · LV2 펭귄 · LV3 뉴욕 택시** — 로 풉니다. 데이터가 계속 달라지므로 배운 검정을 **새 데이터에 적용**하는 훈련이 됩니다. 강사용 완성본은 `정답/` 폴더.

## 1. 교안_01 가설검정 (강사와 함께)

- [ ] 1 가설검정 프레임 — H₀/H₁·유의수준 α·검정통계량·p-value(귀무분포 꼬리)·1종/2종 오류
- [ ] 🔧 주력 도구 **Pingouin**(`pg`) 소개 — 검정+효과크기+신뢰구간을 표 하나로 (대안: scipy/statsmodels)
- [ ] 2 **가정 점검 절차** — ① 집단별 정규성 `pg.normality(dv=, group=)`·`pg.qqplot` → ② 등분산 `pg.homoscedasticity` → ③ 결과 조합으로 검정 선택(Student/Welch·ANOVA/Welch ANOVA·비모수). 정규성이 깨져도 표본이 크면 CLT 로 모수 검정 가능
- [ ] 3 t-검정 3종 — **t 분포와 자유도** 이해 / 1표본 `pg.ttest(x, 기준값)` / 대응 `pg.ttest(a, b, paired=True)` / 독립 `pg.ttest(a, b, correction=)`(Student vs Welch) + Cohen's d(자동)
- [ ] 4 모수 vs 비모수 — 선택 기준, `pg.mwu` + RBC·CLES(**RBC = 2×CLES − 1**), 그리고 나머지 두 짝 **`pg.wilcoxon`(대응)·`pg.kruskal`(3집단+)** 직접 실행
- [ ] 5 분산분석(ANOVA) — `pg.anova`(np2=η²) + 사후검정 `pg.pairwise_tukey`(다중검정 문제) / 이분산이면 `pg.welch_anova`+`pg.pairwise_gameshowell`
- [ ] 6 카이제곱 — 적합도 `scipy.stats.chisquare`(🔧 pg 미지원) / 독립성 `pg.chi2_independence`(Cramér's V 자동) + 조정된 잔차(statsmodels)
- [ ] 7 검정 선택 가이드 — 데이터 유형별 의사결정
- [ ] 🚀 응용 클론코딩 — 교육 전후 **대응표본 t** + 채널별 만족도·재문의율로 **개선안 검증 리포트**
- [ ] ✅ 각 섹션 따라하기 + 바로 확인 퀴즈

## 2. 교안_02 회귀분석 (강사와 함께)

- [ ] 1 상관에서 회귀로 — r → r²(결정계수) → 예측, 상관 ≠ 인과
- [ ] 2 단순 선형회귀 — `smf.ols('y ~ x').fit()`·`.summary()` 읽기(coef·P>|t|·R²), 단순회귀 R² = 상관 r², **예측과 외삽의 위험**
- [ ] 3 다중 선형회귀 — 여러 변수, 계수는 "다른 변수를 고정했을 때"의 효과, Adj R² 로 모형 비교(난수 변수로 벌점 확인), 범주형 변수(더미·기준 범주·더미 함정)
- [ ] 4 회귀 진단 — LINE 4가정, 잔차 vs 적합값·잔차 Q-Q·Durbin-Watson(독립성), 가정 위반 대처
- [ ] 5 종합 워크플로와 한계 — 상관 ≠ 인과, 외삽 위험, 통계적 유의 ≠ 실질적 유의
- [ ] 🚀 응용 클론코딩 — 상관 → 다중회귀(**수치 + 범주형 채널**) → **표준화 계수로 영향력 비교** → 진단(정규성·DW)까지 **만족도 예측 리포트**
- [ ] ✅ 각 섹션 따라하기 + 바로 확인 퀴즈

### 과제_LV3_통합 — 3문 17단계 (권장 150분+) · **뉴욕 택시 운행 기록(taxis)** 데이터

> 지금까지 과제는 이미 깨끗한 데이터로 시작했지만, 이 원본에는 **결측치·불가능한 값·문자로 저장된 날짜**가 섞여 있습니다. **전처리부터 직접** 해야 분석을 시작할 수 있습니다.

- [ ] 1 **원본 전처리** (구조 파악 → 날짜 파싱·`소요시간_분` 파생 → `팁비율` 파생 → 결측 행 제거 → 이상치 제거 → 정제본 저장)
- [ ] 2 **가정 점검과 비교 검정** (정제본 로드 → 정규성·등분산 → Mann-Whitney → **결과 뒤집어 보기** → Kruskal-Wallis + **Dunn 사후검정** + 상자그림 → 카이제곱 + Cramér's V + **조정된 잔차** → 해석 서술)
- [ ] 3 **회귀와 의사결정** (정제본 로드 → 단순회귀 → 다중회귀 → 잔차 진단 그래프·Durbin-Watson → 예측 + 의사결정 리포트)

> **문제 2 의 핵심 함정**: 현금 결제의 팁은 **미터기에 기록되지 않아 전부 0** 입니다. 그래서 '결제수단별 팁비율' 검정은 p ≈ 0 으로 압도적으로 유의하지만, 이는 **승객 행동이 아니라 기록 방식의 차이**입니다. 검정 결과를 해석하기 전에 **그 숫자가 어떻게 만들어졌는지** 확인해야 한다는 것을 직접 겪습니다.

## 막혔을 때

- [ ] 문제 맨 위 `pd.read_csv(...)` 셀부터 다시 실행. 각 문제는 원본 재로딩 또는 `.copy()` 로 시작.
- [ ] 결측치가 있는 열(titanic age·penguins 체중)은 검정 전에 `dropna()`
- [ ] `pg.ttest(a, b)` 의 기본은 Student(`correction=False`) — 등분산을 확신 못 하면 **Welch(`correction=True`)**. 대응표본은 `pg.ttest(a, b, paired=True)`(차이값 정규성만 확인). 결과 표의 `cohen_d`·`CI95`·`power` 를 함께 보기
- [ ] 회귀는 `smf.ols('y ~ x1 + x2', data=df).fit()` → `print(model.summary())` 로 계수·p-value·R² 확인
- [ ] 그래프 문제는 **자동 채점이 없습니다** — 완성 그래프 스크린샷과 같은 모양으로 그리세요
- [ ] p-value 만 보지 말고 **효과크기**(Cohen's d·η²·Cramér's V·Cohen's h)로 "얼마나 큰 차이인지"도 판단
- [ ] 그래도 막히면 강사에게 — 정답 노트북은 스스로 푼 뒤에만 열기
