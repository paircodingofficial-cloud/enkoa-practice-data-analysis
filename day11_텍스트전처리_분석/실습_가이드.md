# 텍스트 전처리·전통 텍스트 분석 가이드 — 진행 체크리스트

지난 단원까지는 **표(정형) 데이터**를 다뤘습니다. 이번 단원부터는 **비정형 텍스트**입니다.
사람의 말·글을 컴퓨터가 셀 수 있는 형태로 바꾸고(**정제·정규표현식·형태소·불용어**), 그 숫자에서 의미를 읽어 냅니다(**빈도·워드클라우드·TF-IDF 핵심어·n-gram·동시 출현**).
완료 기준은 자가채점 `✅ 통과!`(서술·그래프 문제는 서술 셀 작성·완성 그래프처럼 그리기).

> 교안은 **영화 리뷰(네이버 2000건, 긍정/부정)** 로 전 과정을 시연하고, 과제는 **자세밴드 리뷰 → 뉴스 헤드라인 → 선크림 리뷰** 로 도메인을 바꿔 가며 스스로 완성합니다. 강사용 완성본은 `정답/` 폴더.
>
> **함께 따라하기는 시연과 다른 고객 상담 텍스트를 사용합니다.** 영화 리뷰로 개념을 본 뒤 고객 문의·상담 문장에 같은 절차를 적용해, 특정 데이터의 답을 외우지 않고 전처리 → 빈도 → TF-IDF → n-gram → 동시 출현의 흐름을 옮겨 쓰는 연습을 합니다.

## 1. 교안_01 텍스트 전처리 (강사와 함께)

- [ ] 서두: 오늘의 목표 + `⏪ 복습`(표 데이터·시각화) + `데이터 살펴보기`(영화 리뷰 2000건)
- [ ] **이대로는 못 셉니다** — 원문의 노이즈(특수문자·`ㅋㅋㅋ`·`....`)를 눈으로 확인 + **전처리 파이프라인 흐름도**(오늘의 로드맵)
- [ ] 1 정제 — 핵심 정규표현식(`[...]`·`[^...]`·`\d`·`\s`·수량자·그룹/OR·역참조)과
      `find`·`re.search`·`re.findall`·`re.sub` 선택 → 특수문자 제거 → 반복문자 축약 → 공백 정규화 + 🖐️ + ✅
- [ ] 2 토큰화 — 공백 `split()` 의 한계(한국어는 조사가 붙는다, **`영화`가 195가지로 갈라지는 실측 그림**) + 🖐️ + ✅
- [ ] 3 **한국어 형태소 분석(kiwipiepy)** — 조사를 떼고 품사(NN·VA·VV)로 고르기 + 🖐️ + ✅
- [ ] 4 불용어 — ① 일반 불용어 ② **★도메인 불용어를 직접 만들기**(빈도를 보고 판단) + 🖐️ + ✅
- [ ] `🚀 응용 클론코딩` — **전처리 파이프라인 함수**(`clean_text`·`tokenize`) 완성
- [ ] `이번 강의 정리` + `⏭️ 예고`(전통 텍스트 분석)

## 2. 교안_02 전통 텍스트 분석 (강사와 함께)

- [ ] 서두: 목표 + `⏪ 복습`(전처리 파이프라인) + `데이터 살펴보기`
- [ ] 1 단어 빈도 — `Counter`, 긍정·부정 상위 단어 비교 + 🖐️ + ✅
- [ ] 2 워드클라우드 — `font_path` 로 한글 살리기 + 🖐️ + ✅
- [ ] 3 **BoW → TF-IDF** — 개수만 세면 생기는 문제 → 흔한 단어의 힘 빼기
      - `CountVectorizer` vs `TfidfVectorizer` 비교(같은 점·다른 점)
      - **`min_df`·`max_df`** — 정수=문서 수, 소수=문서 비율, `1`과 `1.0`의 차이,
        경계는 `min_df` 미만 제외·`max_df` 초과 제외 + 실제 제거 어휘 확인 + 🖐️ + ✅
- [ ] 4 클래스별 핵심어 — **그리고 그 함정**(공유 노이즈가 양쪽에 섞인다) + 🖐️ + ✅
- [ ] 5 **★차이 기반 특징어**(긍정평균 − 부정평균) — 그 클래스만의 단어
      - 색으로 긍정·부정을 구분한 **통합 워드클라우드** + 🖐️ + ✅
- [ ] 6 **n-gram** — bigram + **선택 가이드**((1,1)/(2,2)/**(1,2) 출발점 후보**) + 🖐️ + ✅
- [ ] 7 **동시 출현**(연관 분석) — 행렬 → 히트맵 → **네트워크 그래프**(전체·긍정·부정 비교) + 🖐️ + ✅
- [ ] 8 **이 방법이 못 하는 일 — TF-IDF 의 한계**(같은 단어가 나와야만 비슷하다고 본다) + 🖐️ + ✅
- [ ] `🚀 응용 클론코딩` — 영화 리뷰 핵심어 리포트
- [ ] `이번 강의 정리` + `⏭️ 예고`(텍스트 벡터화·임베딩)

- [ ] 8 단어 빈도 top20

### 과제_LV3_통합 — 선크림 리뷰 (미니 프로그램 2개)

- [ ] **1 리뷰 텍스트 분석 리포트 생성기**: 1단계 로드 → 2단계 전처리 파이프라인 완성 → 3단계 **도메인 불용어 구축·재적용** → 4단계 빈도·워드클라우드 → 5단계 **차이 기반 특징어**(만족 vs 불만) → 6단계 **별점별 키워드 변화 추적(히트맵)** → 7단계 리포트 표·CSV 저장(`output/`) → 인사이트(서술)
- [ ] **2 연관어 탐색기**: 1단계 문서 준비 → 2단계 bigram top10 → 3단계 동시 출현 행렬·상위 단어쌍 → 4단계 히트맵 → 5단계 **네트워크**(제공 함수 호출) → 인사이트(서술)

## 4. 막혔을 때

- **워드클라우드 한글이 □□□ 로 나와요** — `WordCloud(font_path=FONT_PATH, ...)` 를 빠뜨렸습니다. 맥은 `AppleGothic`, 윈도우는 `Malgun Gothic`.
- **`kiwi.tokenize()` 결과가 이상해요** — 정제(`clean_text`)를 먼저 거친 문장을 넣으세요. 특수문자가 남아 있으면 품사 판정이 흔들립니다.
- **불용어를 지웠는데 여전히 뻔한 단어만 나와요** — **도메인 불용어**를 만들지 않은 것입니다. 빈도 top20 을 눈으로 보고, 이 데이터에서만 의미 없는 말(`제품`·`사용`·`구매` 등)을 골라 추가하세요. 단, 그 도메인의 **핵심어(`착용`·`피부`·`자외선` 등)는 지우면 안 됩니다**.
- **TF-IDF 상위어가 긍정·부정 양쪽에 똑같이 나와요** — 정상입니다. 그래서 **차이 기반 특징어**(한쪽 평균 − 다른쪽 평균)를 씁니다.
- **어휘가 너무 많거나 적어요** — `min_df`(희귀어 제거)·`max_df`(너무 흔한 말 제거)를 조절하세요. 기준은 출현 "횟수"가 아니라 그 단어가 든 **문서 수**입니다.
- **그래프가 겹쳐 그려져요** — 그래프마다 `fig, ax = plt.subplots()`로 새 Figure와 Axes를 만들고, seaborn 함수에는 `ax=ax`를 넘기세요.
