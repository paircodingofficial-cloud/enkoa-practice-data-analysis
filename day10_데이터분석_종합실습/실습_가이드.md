# 데이터 분석 종합 실습(MVP) 가이드 — 진행 체크리스트

6~9일차에서 하나씩 배운 도구(판다스 정제·EDA 시각화·기술통계·추론통계·가설검정·회귀)를 **하나의 비즈니스 문제**에 통합해, **문제 정의 → 전처리 → EDA → 통계 검정 → 인사이트 리포트**의 전 과정을 스스로 완성하는 하루입니다.
새 기법은 배우지 않습니다 — **지금까지 배운 것을 엮어 결론을 내는** 연습입니다.

> ⚠️ **오늘은 강사가 앞에서 풀어 주지 않습니다.** 발제문(LMS 문서)과 세 개의 가이드 노트북만 주어지고, **분석은 여러분이 설계합니다.** 정답이 하나로 딱 떨어지지 않는 것이 정상입니다 — 채점되는 것은 **사실 확인 몇 곳뿐**이고, 나머지는 **분석 과정과 인사이트 서술**이 핵심입니다.
>
> 데이터는 실제 글로벌 패션기업 **H&M** 의 고객·거래·상품 3개 테이블 하나로 관통합니다. `price` 는 정규화된 상대값(SEK 아님)이라 **상대 비교에만** 씁니다. 강사용 예시 풀이는 `정답/` 폴더 — **"정답"이 아니라 "이렇게도 할 수 있다"의 한 사례**입니다.

## 1. 01 데이터 이해 & 전처리 — 이 프로젝트의 중심

> 여기가 오늘의 **가장 중요한 파트**입니다. 전처리를 건너뛰면 뒤의 검정 결과를 믿을 수 없습니다.

- [ ] **1장 문제 정의** — 비즈니스 질문 → 분석 질문 → 데이터 질문으로 좁히기, 좋은/나쁜 질문 대비, 이해관계자별 질문, **가설(H0/H1)**, 분석 계획표
- [ ] **2장 데이터 이해** — 3테이블 구조·데이터 사전·키 컬럼 확인 (✅ 자가채점: 원본 shape)
- [ ] **3장 함정 확인** — 나이 이상값(0·3·7·130·999)·0 이하 가격·정의에 없는 채널 코드·멤버십 결측
      · **IQR 규칙과 Z-score 가 10세 미만을 한 명도 못 잡는 것**을 직접 확인 → *기계적 규칙 vs 도메인 판단*
- [ ] **4장 전처리 규칙 수립** — 항목별 트레이드오프(무엇을 얻고 무엇을 잃는가)를 검토한 뒤 **결정 기록표** 작성
- [ ] **5장 테이블 결합** — merge 후 행수 검증 (✅ 자가채점: 조인 직후 행수)
- [ ] **6장 규칙 적용 & 파생변수** — 처리 로그(단계별 전후 행수) + `month`·`weekday`·`age_group`
- [ ] **7장 정제본 저장** — `output/hm_clean.csv` 로 직접 저장
      · 파생 컬럼 3개(`month`·`weekday`·`age_group`)를 만든 뒤에 저장하세요. 02·03 이 그 컬럼들을 씁니다
      · 저장 후 **다시 읽어 행수·컬럼을 확인**하세요 — 저장이 안 된 것을 02 에서 알게 되면 되돌아와야 합니다

## 2. 02 데이터 EDA

- [ ] 01 이 저장한 정제본(`output/hm_clean.csv`)을 **직접 불러오기** — 01 을 끝내지 않았으면 02·03 을 시작할 수 없습니다
- [ ] **집계 3형제** — `groupby` vs `pivot_table` vs `crosstab`, **언제 무엇을 쓰는지**
- [ ] **변수 개수로 그래프 고르기** — 단변량(hist·box·count) / 이변량(scatter·bar·line) / 다변량(heatmap·hue·subplots)
- [ ] 기술통계 — 대표값(평균·중앙값·최빈·절사평균)·산포(IQR·표준편차·변동계수)·분포(왜도·첨도)·로그 변환
- [ ] 상관 — 피어슨·스피어만·히트맵, **상관 ≠ 인과**
- [ ] **필수 미션 2개** — ① 기술통계 제시 ② 기준 컬럼 비교분석 + 시각화
- [ ] **선택 미션 8개 중 하고 싶은 것** (★ 쉬움 → ★★★ 어려움)
      · ★ 산점도 등 다양한 형식 / 고객 속성 × 채널 교차분석
      · ★★ 로그·정규화(z-score·Min-Max) 분포 비교 / 이상치 고객·거래 탐색 / 월별·분기별 추세와 시즌성 / 채널 비중 보정(비율·ARPU)
      · ★★★ 고객별 총 구매액 상위 20% vs 하위 20% / 월별 매출 3개월 롤링 평균
- [ ] 그림마다 **무엇을 말하는지 한 줄**, 그리고 절 끝에 **종합 인사이트 한 문단** — "무엇이 보이는가"가 아니라 "그래서 무엇을 뜻하는가"
- [ ] 03 으로 넘길 **질문 2개**를 남기기 (눈으로 본 차이가 우연인지 검정으로 확인할 것)

## 3. 03 데이터 통계 & 인사이트 리포트

- [ ] **가정 점검 절차** — ① 집단별 정규성(`pg.normality` + **Q-Q Plot 함께**) → ② 등분산(Levene) → ③ 검정 선택표
- [ ] 검정별 지침 훑기 — 추론통계(CLT·표준오차·신뢰구간·p-value) / t-검정 3종 / 비모수(MWU·Wilcoxon) / ANOVA·Kruskal + **사후검정**(Tukey·Games-Howell·Dunn) / 카이제곱 + **조정된 잔차** / 회귀 + **LINE 4가정 진단**
- [ ] **선택 통계 미션 A~E 중 최소 1개** — 채널 단가 / 연령대 단가 / 연령대×채널 독립성 / 멤버십 단가 / 회귀+LINE
      · 통계는 **필수가 아닙니다** — 하지만 "눈에 보이는 차이"를 주장하려면 근거가 필요합니다
- [ ] **효과크기를 항상 함께** — 11만 건에서는 아주 작은 차이도 p 가 유의해집니다 (Cohen's d·η²·Cramér's V)
- [ ] **최종 인사이트 리포트**(필수) — 5요소 뼈대 + 한계 3가지(표본 편향·상관≠인과·price 정의)
- [ ] **AI 협업 검증** — AI 초안의 숫자 3개를 직접 재계산해 대조 (✅ 자가채점: 이 3개만)
- [ ] 제출 체크리스트 8항목 확인

- [ ] **어떤 검정을 쓸지 모르겠다** → 03 의 **검정 선택표**(정규성 → 등분산 → 조합별 선택)를 보세요. 변수 유형(수치×수치 / 범주×수치 / 범주×범주)이 검정을 결정합니다
- [ ] **3테이블 결합** → `customer_id`·`article_id` 로 `merge`(inner). 완전히 똑같은 거래 행은 정상 다구매일 수도 있으니 **중복 제거는 판단**해서 하세요
- [ ] **검정 호출법** → 9일차 그대로 **Pingouin** — `pg.ttest(a, b, correction=True)` · `pg.anova(data, dv, between, detailed=True)` · `pg.pairwise_tukey` · `pg.chi2_independence`. **회귀만 statsmodels** `smf.ols('y ~ x1 + x2', data=df).fit()`
- [ ] **그림이 안 예쁘다** → 오늘은 채점 대상이 아닙니다. **읽히는가**만 보세요(축 라벨·단위·제목)
- [ ] **인사이트가 안 써진다** → 03 의 "숫자를 말로 옮기는 법"과 좋은 예/나쁜 예 대비를 보세요. 순서는 **숫자 재진술 → 유의성 + 효과크기 → (작으면) 실질적 한계 → 방향성 결론 → 관찰연구는 인과 아님**
- [ ] 그래도 막히면 강사에게 — `정답/` 은 **스스로 해 본 뒤에만** 열기(그마저도 한 가지 예시일 뿐)
