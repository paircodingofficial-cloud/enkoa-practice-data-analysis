# EDA·시각화 실습 가이드 — 진행 체크리스트

pandas 로 데이터를 **결합·집계해 요약**하고, matplotlib·seaborn 으로 **데이터 유형에 맞는 그래프**를 골라 그려 인사이트를 뽑는 하루입니다.
아래 체크박스를 순서대로 지워 나가세요. 각 과제의 완료 기준은 **자가채점 셀에서 `✅ 통과!` 가 출력되는 것**입니다(서술형 문제는 서술 셀 작성, **그래프 문제는 문제 설명 아래 제시된 "완성 그래프(정답)" 와 같은 모양으로 그리기**).

> 교안은 강사 **시연**을 **레스토랑 팁·항공 여객·펭귄** 데이터로 보고, **함께 따라하기는 시연과 다른 데이터 — 피트니스 센터 이용 기록**(`gym_visits.csv`·`program_info.csv`) 으로 직접 연습합니다. 과제는 또 레벨마다 다른 데이터 — **LV1 타이타닉 · LV2 택시 · LV3 다이아몬드** — 로 풉니다. 데이터가 계속 달라지므로 배운 개념을 새 데이터에 **적용**하는 훈련이 됩니다. 강사용 완성본은 `정답/교안_01_정답.ipynb`·`정답/교안_02_정답.ipynb`.

## 1. 교안_01 결합·집계로 데이터 요약 (강사와 함께)

- [ ] 1 groupby — 그룹으로 묶어 mean·sum·size 로 요약, `groupby(key)[col].집계`, **기준 자리엔 범주형**(연속형은 `pd.cut` 으로 구간화)·집계 대상은 **주로 수치형이나 범주형도 가능**(세기·최빈값)
- [ ] 2 groupby 심화 — 여러 키 `groupby([k1,k2])`, 여러 집계 `agg(['mean','sum','count'])`, 열마다 다른 집계 `agg({'열':'함수'})`, `as_index=False`
- [ ] 3 groupby 사용자 정의 집계 — `lambda`·`def` 로 목록에 없는 계산, 열 이름 붙이기 `agg(이름=('열', 함수))`, `agg`(한 열) vs `apply`(여러 열), **범주형 집계**(최빈값 `mode`·종류 수 `nunique`·값 목록·최빈값 점유율)
- [ ] 4 pivot_table — `index`·`columns`·`values`·`aggfunc`, 총계 `margins=True`, 빈칸(NaN)이 생기는 이유와 `fill_value=`
- [ ] 5 crosstab — 범주 × 범주 **빈도표**, 비율 `normalize='index'`(행 기준)·`'columns'`(열 기준)
- [ ] 6 merge — 두 표를 키로 잇기 `on=`, 방식 `how=`(inner·left·right·outer) 차이, 키 이름이 다를 때 `left_on`/`right_on`, 열 충돌 시 `suffixes`, **행이 늘어나는 함정**과 `validate='m:1'`
- [ ] 7 concat — 표를 이어 붙이기(행 `axis=0`·열 `axis=1`), merge 와의 차이, 컬럼이 다르면 열이 갈라지고 NaN 이 생김(`join='inner'`)
- [ ] 🚀 응용 클론코딩 — 병합 → 여러 키 그룹 → 여러 집계 → 격자표 → 정렬로 **집계 리포트** 완성
- [ ] ✅ 각 섹션 따라하기 + 바로 확인 퀴즈 전부 풀고 정답 보기로 확인

- [ ] 0 오늘의 데이터 — 레스토랑 팁(분포·범주)·펭귄(관계·다변량, 결측 11행)·항공 승객(시계열, month 는 문자열) 세 표를 `head`·`info`·`describe` 로 확인

- [ ] 5 관계 — `scatterplot`(+`hue`/`size`/`style`), 점의 흩어짐으로 관계를 눈으로 읽기

- [ ] 9 구성·기타 — 파이·누적막대(부분→전체 비율), `stripplot`/`swarmplot`·`ecdfplot`·`jointplot`
