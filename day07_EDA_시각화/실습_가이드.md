# EDA·시각화 실습 가이드

pandas 로 데이터를 **결합·집계해 요약**하고, matplotlib·seaborn 으로 **데이터 유형에 맞는 그래프**를 골라 그려 인사이트를 뽑는 하루입니다.
오늘 할 일은 **교안 2권을 강사와 함께 따라간 뒤, 과제 LV1~LV3 을 스스로 푸는 것**입니다. 각 문제의 완료 기준은 **자가채점 셀에서 `✅ 통과!` 가 출력되는 것**이고, 서술형은 서술 셀을 채우면 됩니다. **그래프 문제는 자동 채점이 없으니**, 문제 설명 아래 제시된 "완성 그래프(정답)" 와 같은 모양이 되도록 그리세요.

> 교안은 강사 **시연**을 **레스토랑 팁·항공 여객·펭귄** 데이터로 보고, **함께 따라하기는 시연과 다른 데이터 — 피트니스 센터 이용 기록**(`gym_visits.csv`·`program_info.csv`) 으로 직접 연습합니다. 과제는 또 레벨마다 다른 데이터 — **LV1 타이타닉 · LV2 택시 · LV3 다이아몬드** — 로 풉니다. 데이터가 계속 달라지므로 배운 개념을 새 데이터에 **적용**하는 훈련이 됩니다. 강사용 완성본은 `정답/교안_01_정답.ipynb`·`정답/교안_02_정답.ipynb`.

## 0. 준비 (수업 시작 전, 약 5분)

- [ ] **실습 환경을 준비**하세요 — 받은 자료 폴더에서 아래 한 줄이면 끝입니다.

```bash
uv sync
```

  `uv sync` 는 자료에 함께 들어 있는 `pyproject.toml`·`uv.lock` 을 읽어 **거기 고정된 버전 그대로** 설치합니다.
  그래서 강사와 수강생, 그리고 옆자리 동료까지 **모두 똑같은 환경**이 됩니다
  (Python 3.12 · pandas 2.3 · matplotlib 3.11 · seaborn 0.13 · numpy · scipy · openpyxl).
  버전이 어긋나서 생기는 "제 화면에선 되는데요" 를 막아 주는 것이 이 명령의 목적이에요.

- `--python 3.12` 를 주면 `.python-version` 에 `3.12` 가, `pyproject.toml` 에 `requires-python = ">=3.12"` 가 기록됩니다.
  이 버전을 정해 두지 않으면 사람마다 다른 파이썬으로 환경이 만들어져, 위에서 말한 "같은 환경" 이 깨집니다.
- `"pandas<3"` 처럼 **버전 조건**을 붙일 수도 있습니다(따옴표는 `<` 를 셸이 아니라 uv 에게 넘기기 위한 것). 이 수업은 pandas 2 로 맞춰져 있어요 —
  pandas 3 에서는 일부 에러 메시지 문구가 달라져 교안 설명과 화면이 어긋납니다. 조건 없이 `uv add pandas` 만 하면 늘 최신(3.x)이 깔립니다.

새 패키지를 쓰고 싶을 때도 `uv add <이름>` 으로 추가하면 됩니다. 반대로 이미 만들어진 자료를 받았다면 `uv add` 를 다시 할 필요 없이 **`uv sync` 만** 하면 됩니다.

## 막혔을 때

**① 값이 이상하거나 셀이 꼬였다면**

- 그 문제 맨 위의 `pd.read_csv(...)` 셀부터 다시 실행하세요. 앞 문제에서 가공한 표가 섞여 들어온 경우가 대부분입니다.
- 그래도 이상하면 커널을 재시작한 뒤 **위에서부터 순서대로** 다시 실행하세요.

**② 어떻게 풀지 모르겠다면**

- 문제의 `힌트` 접기를 열어 **접근방법 → 세부구현** 순서로 다시 설계해 보세요. 정답 코드가 아니라 *순서*를 알려 주는 힌트입니다.
- 그래도 안 잡히면 교안에서 그 도구를 쓴 절을 다시 봅니다 — **집계**가 헷갈리면 교안_01 의 1~3번, **`merge`** 가 헷갈리면 6번의 `how=` 그림, **어떤 그래프를 쓸지**가 헷갈리면 교안_02 의 2번 선택 지도.

**③ 그래프가 예시와 다르게 나온다면**

- `ax = sns.…(...)` 로 결과를 받아 `ax.set_title(...)` 로 제목을 답니다. 축 이름은 seaborn 이 컬럼명으로 자동으로 달아 줍니다.
- 막대그래프에는 `errorbar=None` 을 붙이세요 — 없으면 평균 위에 오차막대가 함께 그려져 모양이 달라집니다.
- 앞 그림 위에 겹쳐 그려지면, 그리기 전에 `plt.figure()` 로 **새 도화지**를 여세요.
- 한글이 깨지면 폰트 줄만 OS 에 맞게 바꿉니다 (`AppleGothic` ↔ `Malgun Gothic`).

**④ 그래도 막히면**

- 강사에게 물어보세요. **정답 노트북은 스스로 한 번 끝까지 시도한 뒤에** 여는 것이 남는 게 많습니다.
