## 실행 전에 확인할 것

- 정답 노트북은 각 일차 폴더의 `data/`·`images/` 를 그대로 읽습니다(예: `../../day06_판다스_기초/data/...`). 저장소 폴더 구조를 유지한 채 열어야 경로가 맞습니다.
- 산출물은 노트북과 같은 폴더의 `output/` 에 만들어집니다.
- `day13` 의 OpenAI 호출 문제는 `day13_토픽모델링_심화/.env` 에 `OPENAI_API_KEY` 가 있을 때만 실행되고, 없으면 건너뜁니다.
