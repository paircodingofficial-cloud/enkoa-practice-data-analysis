# 판다스 기초 실습 가이드 — 진행 체크리스트

pandas 로 표 데이터를 불러오고, 골라내고, 정제하고, 새 정보를 만드는 하루입니다.
아래 체크박스를 순서대로 지워 나가세요. 각 과제의 완료 기준은 **자가채점 셀에서 `✅ 통과!` 가 출력되는 것**입니다.

> 교안은 데모를 **카페 판매 데이터**로 보고, **따라하기는 데모와 다른 서점 판매 데이터**(`bookstore_sales.csv`)로 직접 연습합니다. 과제는 또 다른 **중고차·쇼핑몰·시험 성적** 데이터로 풉니다. 데이터가 계속 달라지므로 배운 개념을 새 데이터에 **적용**하는 훈련이 됩니다. 강사용 완성본은 `정답/교안_01_정답.ipynb`·`정답/교안_02_정답.ipynb`.

## 0. 준비 (수업 시작 전, 약 5분)

- [ ] **실습 환경을 준비**하세요 — 받은 자료 폴더에서 아래 한 줄이면 끝입니다.

```bash
uv sync
```

  `uv sync` 는 자료에 함께 들어 있는 `pyproject.toml`·`uv.lock` 을 읽어 **거기 고정된 버전 그대로** 설치합니다.
  그래서 강사와 수강생, 그리고 옆자리 동료까지 **모두 똑같은 환경**이 됩니다
  (Python 3.12 · pandas 2.3 · matplotlib 3.11 · seaborn 0.13 · numpy · scipy · openpyxl).
  버전이 어긋나서 생기는 "제 화면에선 되는데요" 를 막아 주는 것이 이 명령의 목적이에요.
  **한 번만 실행하면 이후 일차까지 함께 준비**되니, 다음 수업에서 다시 할 필요는 없습니다.

<details><summary>참고 — 빈 폴더에서 직접 환경을 만들어 볼 때</summary>

자료 없이 처음부터 만들어 보고 싶다면 아래처럼 **필요한 것을 하나씩 추가**합니다.
`uv add` 는 설치와 동시에 `pyproject.toml`·`uv.lock` 에 그 패키지를 기록해 둡니다 — 그렇게 만들어진 것이 위에서 `uv sync` 가 읽는 파일이에요.

```bash
uv init --python 3.12                       # 파이썬 버전을 3.12 로 정해 프로젝트 만들기
uv add jupyter "pandas<3"                   # day06 (jupyter 안에 VS Code 커널용 ipykernel 포함)
```

- `--python 3.12` 를 주면 `.python-version` 에 `3.12` 가, `pyproject.toml` 에 `requires-python = ">=3.12"` 가 기록됩니다.
  이 버전을 정해 두지 않으면 사람마다 다른 파이썬으로 환경이 만들어져, 위에서 말한 "같은 환경" 이 깨집니다.
- `"pandas<3"` 처럼 **버전 조건**을 붙일 수도 있습니다(따옴표는 `<` 를 셸이 아니라 uv 에게 넘기기 위한 것). 이 수업은 pandas 2 로 맞춰져 있어요 —
  pandas 3 에서는 일부 에러 메시지 문구가 달라져 교안 설명과 화면이 어긋납니다. 조건 없이 `uv add pandas` 만 하면 늘 최신(3.x)이 깔립니다.

새 패키지를 쓰고 싶을 때도 `uv add <이름>` 으로 추가하면 됩니다. 반대로 이미 만들어진 자료를 받았다면 `uv add` 를 다시 할 필요 없이 **`uv sync` 만** 하면 됩니다.
