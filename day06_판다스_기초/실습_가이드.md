pandas 로 표 데이터를 불러오고, 골라내고, 정제하고, 새 정보를 만드는 하루입니다.
아래 체크박스를 순서대로 지워 나가세요. 각 과제의 완료 기준은 **자가채점 셀에서 `✅ 통과!` 가 출력되는 것**입니다.

> 교안은 **카페 판매 데이터**로 배우고, 과제는 **중고차·쇼핑몰·시험 성적** 데이터로 풉니다. 데이터가 달라 배운 개념을 새 데이터에 **적용**하는 훈련이 됩니다. 강사용 완성본은 `정답/교안_01_정답.ipynb`·`정답/교안_02_정답.ipynb`.

## 1. 교안_01 데이터프레임·조회·선택·정렬 (강사와 함께)

- [ ] DataFrame 생성·조회 — 딕셔너리·`read_csv` 로 만들고 `head`·`shape`·`columns`·`dtypes`·`info`·`describe` 로 살펴보기
- [ ] 열 선택 — `df['열']`(시리즈) vs `df[['열1','열2']]`(데이터프레임) 차이
- [ ] 행 인덱싱 — `loc`(라벨, 끝 포함) vs `iloc`(위치, 끝 제외), 행·열 교차 선택
- [ ] 불리언 필터 — 조건식, `&`·`|`·`~` (괄호 필수), `isin`, `between`
- [ ] 열·행 다루기 — 필요 없는 열·행 버리기 `drop`, 컬럼 이름 바꾸기 `rename`
- [ ] 정렬 — `sort_values` 단일·다중 열·`ascending` 리스트, 중복 제거 `drop_duplicates`
- [ ] 🚀 응용 클론코딩 — 조회→선택→필터→정렬 한 흐름
- [ ] ✅ 바로 확인 퀴즈 전부 풀고 정답 보기로 확인

## 2. 교안_02 결측·이상치·형변환·문자열·파생 (강사와 함께)

- [ ] 결측치 — `isna`·`isna().sum()`·`dropna`·`fillna`(값·평균·앞뒤값 `ffill`/`bfill`)
- [ ] 이상치 — 임계값 불리언 필터로 탐지·제거, `clip`, 중앙값이 이상치에 강건한 이유
- [ ] 자료형 변환 — `astype`, `to_numeric(errors='coerce')`, `to_datetime`, 콤마 숫자는 `.str.replace(',','')` 후 변환
- [ ] 문자열 처리 — `.str.strip`·`.str.replace`·`.str.contains`·`.str.split`·`.str.lower`, 문자열 `+` 결합(`astype(str)`)
- [ ] 파생 변수 — 새 컬럼 대입, `apply`(사용자 함수), `map`(딕셔너리), 조건 파생(`np.where`)
- [ ] 🚀 응용 클론코딩 — 지저분한 원본 → 정제 → 파생까지 미니 파이프라인
