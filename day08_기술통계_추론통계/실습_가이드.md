# 기술통계·추론통계 실습 가이드 — 진행 체크리스트

표(데이터)를 **숫자로 요약**하고(기술통계), 확률·분포로 **불확실성을 다루며**, 표본으로 **모집단을 추측**하는(추론통계) 하루입니다.
아래 체크박스를 순서대로 지워 나가세요. 각 과제의 완료 기준은 **자가채점 셀에서 `✅ 통과!` 가 출력되는 것**입니다(서술형은 서술 셀 작성, **그래프 문제는 문제 설명 아래 "완성 그래프(정답)" 와 같은 모양으로 그리기**).

> 통계는 별도 이론 수업이 없으므로 **교안에 이론을 충분히 담았습니다** — 설명 → 시연 → 따라하기 → 퀴즈 순으로 읽고 실행하세요.
>
> 교안은 강사 **시연**을 **자동차 연비(mpg)** 로 보고, **함께 따라하기는 시연과 다른 데이터 — 음료 제조 공장 품질검사 기록**(`factory_quality.csv`)으로 직접 연습합니다. 과제는 또 레벨마다 다른 데이터 — **LV1 펭귄 · LV2 국가 보건지출 · LV3 고객 마케팅** — 로 풉니다. 데이터가 계속 달라지므로 배운 개념을 **새 데이터에 적용**하는 훈련이 됩니다. 강사용 완성본은 `정답/` 폴더.

## 1. 교안_01 기술통계·확률·상관 (강사와 함께)

- [ ] 1 대표값 — 평균·중앙값·최빈값·절사평균(`stats.trim_mean`)·가중평균(`np.average(weights=)`), 평균의 함정
- [ ] 2 산포도 — 범위·IQR(`stats.iqr`)·분산/표준편차(`ddof=1` 베셀 보정)·변동계수(CV), 이상치(IQR 1.5배·Z-score)

- [ ] 4 상관 분석 — 산점도, 피어슨(`stats.pearsonr`·`df.corr`)·스피어만(`stats.spearmanr`), 상관행렬 히트맵, **상관 ≠ 인과**
- [ ] 5 확률 기초 — 대수의 법칙, 확률 법칙(덧셈·곱셈·조건부·독립/배반), 기대값·분산

- [ ] 7 정규분포 심화 — 표준화·Z-score, 68-95-99.7 법칙, `norm.cdf`·`norm.ppf`
- [ ] 7-2 **정규성 확인** — 정규분포 공식을 쓰기 전에 가정부터: 히스토그램+정규곡선, Q-Q Plot(`stats.probplot`), 왜도·첨도와 68-95-99.7 실측 대조 (정규성 *검정*은 다음 단원)
- [ ] 🚀 응용 클론코딩 — 라인별 품질 요약 → 불량 상관 → 규격 이탈 확률로 **품질 리포트 한 장** 완성

## 2. 교안_02 통계적 추론 (강사와 함께)

- [ ] 1 모집단 vs 표본 — 모수 vs 통계량, 표본분포(`df.sample`)
- [ ] 2 중심극한정리(CLT) — n 이 커지면 표본평균 분포가 정규로 (`rng.choice` 시뮬레이션)
- [ ] 3 표준오차 — `SE = σ/√n`(`stats.sem`), n 4배면 SE 절반
- [ ] 4 점추정 vs 구간추정 — 하나의 숫자에서 오차를 담은 범위로
- [ ] 5 신뢰구간 — 부트스트랩(`np.percentile`)·공식(`stats.norm.interval`·`stats.t.interval`), **올바른 해석**과 신뢰수준 맞바꿈
- [ ] 6 신뢰구간으로 주장 판단 — 신뢰구간이 주장값을 포함하는지로 판단 (정식 가설검정은 다음 시간)
- [ ] 7 **p-value 직관** — 주장이 맞다고 가정했을 때 지금 본 결과가 얼마나 드문가. 시뮬레이션(`rng.choice`)으로 만들어 보고 공식(`stats.t.sf`, 양측 ×2)으로 확인, **신뢰구간 밖 ⟺ p < 0.05**, p-value 흔한 오해 4가지
- [ ] 🚀 응용 클론코딩 — 표본 하나로 점추정 → 표준오차 → 신뢰구간 → 주장 판단까지 **추론 리포트** 쓰기

## 3. 과제 (자기 주도, 자가채점 `✅ 통과!` 기준)

### 과제_LV1_기초 — 16문 (권장 100분 내외) · **펭귄(penguins)** 데이터

- [ ] 1 데이터 살펴보기 (서술형)
- [ ] 2 평균과 중앙값
- [ ] 3 절사평균 (trim_mean)
- [ ] 4 분산과 표준편차 (ddof=1)
- [ ] 5 IQR과 이상치 — 경계값(1750~6550)과 1.5×IQR 규칙 이상치 수
- [ ] 6 변동계수 (CV, **백분율 %** — 교안·LV2·LV3 와 동일 표기)
- [ ] 7 왜도와 첨도 (stats.skew · stats.kurtosis)
- [ ] 8 두 변수의 관계 — 산점도 (그래프)
- [ ] 9 피어슨 상관계수
- [ ] 10 스피어만 상관과 '상관 ≠ 인과' (계산 + 서술)
- [ ] 11 상관행렬 히트맵 (그래프)
- [ ] 12 정규분포로 확률 구하기 (norm.cdf)
- [ ] 13 이항분포로 확률 계산 (binom.pmf · cdf)
- [ ] 14 포아송분포로 확률 계산 (poisson.pmf · cdf)
- [ ] 15 Z-score와 경험 규칙 (표준화 · 68-95-99.7 · **|Z|>2 이상치** — 문제 5 의 IQR 규칙과 결과 비교)
- [ ] 16 정규분포 커트라인 구하기 (norm.ppf · 상위 10%)

### 과제_LV2_응용 — 11문 (권장 135분 내외) · **국가 보건지출(healthexp)** 데이터

- [ ] 1 데이터 관찰 (서술)
- [ ] 2 미국의 지출 요약 통계 (필터 + 기술통계)
- [ ] 3 최근 연도 지출 1위·최하위 나라와 격차 (필터 + 최댓값·최솟값·격차)
- [ ] 4 지출과 기대수명 산점도 + 관찰 (그래프 + 해석)
- [ ] 5 지출과 기대수명의 상관계수 (피어슨 + 해석)
- [ ] 6 순위로 본 상관 (스피어만 + 비교)
- [ ] 7 표본평균의 분포 — 중심극한정리 (시뮬레이션 + 자가채점 + 관찰)
- [ ] 8 기대수명 평균의 95% 신뢰구간 (공식)
- [ ] 9 두 주장을 **p-value** 로 견주기 (`stats.t.sf`, 양측 ×2) + 신뢰구간과의 등가 (계산 + 서술)
- [ ] 10 세 변수 상관행렬 히트맵 + 관찰 (그래프 + 해석)
- [ ] 11 인사이트 리포트 (종합 서술)

### 과제_LV3_통합 — 2문 (권장 120분+) · **고객 마케팅(marketing_campaign)** 데이터

- [ ] 1 고객 기술통계 리포트 (로드·구조 → 정제(결측·오염) → 파생(총지출·나이) → 대표값·산포 → 분포 → 상관행렬 → 소득 평균 95% 신뢰구간 → 인사이트, 단계별 자가채점)
- [ ] 2 지출·반응 심화 리포트 (정제·파생 재사용 → 교육수준별 비교(groupby) → 결혼상태별 지출 분포 → 반응별 평균 차이 → 상관 → 인사이트)
